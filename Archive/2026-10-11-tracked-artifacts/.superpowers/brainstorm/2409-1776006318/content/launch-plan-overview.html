Final Launch Polish — The Plan

Three phases to go from 8.4 to perfection. No triage, no shortcuts. Every pixel, every interaction, every page.

THE APPROACH

This is structured as three sequential phases. Each phase completes fully before the next begins. Phase 3 loops until zero issues remain.

1

Phase 1: Enhancement Sweep

Visual + Interaction + Flow polish — not new features, but making every existing surface feel world-class.

  • Visual: Page-by-page pixel audit. Spacing rhythm, color consistency, elevation hierarchy, typography polish, light mode parity
  • Interaction: Every click, hover, transition, keyboard shortcut. Spring physics tuning. Optimistic UI verification. Undo toast coverage.
  • Flow: User journey walkthroughs (new team member, PI checking status, coordinator prepping meeting). Find friction, eliminate dead ends.
  • Homepage: Full public site redesign audit — hero, stats, pillars, footer. Mobile responsive check.
  • Empty states: Every page with <3 items gets a purposeful, branded empty state that sells the feature.
  • Data quality: Populate real decisions, archive stale projects, calibrate health algorithm, seed missing data.
2

Phase 2: Rigorous Implementation

Execute every enhancement from Phase 1 — subagent-driven development with spec review + code quality review after each task.

  • Commit discipline: One concern per commit. Atomic, reversible changes.
  • Build verification: TypeScript check + Vite build after every change.
  • No deploy until complete: Everything lands on main, single deploy at the end.
  • Cross-reference: Every change checked against design system tokens, CLAUDE.md rules, accessibility requirements.
3

Phase 3: Audit → Fix → Audit Loop

Deploy, then audit everything. Fix what's found. Redeploy. Audit again. Repeat until zero issues.

  • Round 1: Full Playwright interaction test (every page, every click, every dropdown, every keyboard shortcut). Screenshot every page both modes. Expert panel re-scores.
  • Round 2: Fix everything found. Redeploy. Re-run full test suite. Re-screenshot. Compare.
  • Round 3+: Continue until: 0 test failures, 0 visual regressions, expert score ≥9.0, every page visually verified by me personally.
  • Final gate: Playwright records a full user journey video (new member onboarding → tasks → meetings → projects) with zero friction points.
SCOPE — WHAT THIS COVERS
Public Site (5 pages)
  • Homepage hero + nav + stats + pillars
  • Team page + member profiles
  • Publications page
  • Contact page
  • Footer across all public pages
Portal (17+ pages)
  • Dashboard, Tasks, Projects, Meetings
  • Personal, Deadlines, Manuscripts, Grants
  • Ideas, Decisions, Calendar, Analytics
  • Search, Settings, Activity, Research Digest
  • All detail pages (Project, Meeting, Member)
  • All modals, dropdowns, panels, toasts
WHAT THIS DOES NOT INCLUDE

New features, new pages, new API endpoints, new database tables. This is purely about making what exists feel perfect. The only "new" things are empty states, micro-interactions, and transition refinements.
